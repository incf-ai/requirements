# Glossary

Shared terminology used across this project's requirements, tests, and
results. Lives here (the project root's `attachments/`) rather than under
any single requirement/test/result so anything in the project can reference
it via `ModuleAttachmentReferenceV1`.

- **Stage** — one step in a requirement's lifecycle (e.g. `definition`,
  `discovery`, `implementation`).
- **Result kind** — how a test expects a satisfying result to be attached:
  `FreeForm` or `Template`.
